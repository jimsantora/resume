Resume restart: three TUI directions

Each one uses the real resume content at full size. Click around and resize; they all work with the mouse, and keys are a bonus. No fake commands anywhere.

  1. DHybrid (new)C's layout, k9s's marks C's roomy list-and-detail reading layout, wearing k9s: orange info labels, <n> hotkeys, the window title set into the border, a solid aqua selection bar, crumbs. Saturated colours, no pastels. Press s (or click "skin" bottom right) to compare a dark and a light skin.
  2. APanelsafter lazygit Numbered panels down the left (status, experience, skills, game credits), one detail pane on the right. Skills show which jobs used each tool. On a phone the detail opens under the panel you tapped.
  3. BTableafter k9s Info header with the links up top, view hotkeys beside it, one big resource table. Click a row to describe it, breadcrumbs to go back. The most data-dense of the three.
  4. CCharmafter bubbletea Name badge, tabs joined to a rounded window, list with a selected-item bar and a detail box. The softest and roomiest, and the only one with a light mode.

Which one is closest? It's fine to mix them, e.g. "B's header with C's colors", or to say what you like in lazygit, k9s or bubbletea that none of these got.
